# Abdullah_OS — Interactive 3D Game Launcher Portfolio

A complete Vite + React + TypeScript + React Three Fiber portfolio based on the supplied specification.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Controls

- Click 3D modules to fly the camera into them.
- `ESC` closes an interface.
- `CTRL+K` or `~` opens the developer terminal.
- `M` opens the module map.
- Use the HUD quality selector and Reduce Motion control.
- Audio is muted by default.

## Notes

The scene uses procedural Three.js geometry, so it runs without external 3D assets. Replace the `#` social links and `/Abdullah-Naveed-CV.pdf` path when your real links/CV are ready.

The project data is centralized in `src/data.ts`.
